🌐 Cloudflare / Reverse Proxy

This router speaks plain HTTP and has no TLS of its own, so it is meant to sit behind Cloudflare Tunnel or another reverse proxy that terminates HTTPS. The two switches below fix the problems that setup creates. Use Copy config to get a ready-to-paste cloudflared file.

alt_route Trust proxy headers

Reads X-Forwarded-For to identify the real client. Without it every visitor looks like the proxy's own IP, so five wrong passwords from anyone lock out everyone.

⚠️ Only turn this on once the port is NOT reachable directly from the internet. A direct client could forge the header to dodge the login limiter.

lock Secure session cookie

Adds the Secure flag to the login cookie so browsers never send it over an unencrypted hop. Turn on when the public URL is HTTPS.

⚠️ If the site is HTTPS but the origin sees plain HTTP, the cookie would otherwise be sendable in the clear. Leave off only while testing over plain HTTP on localhost.

💾 Backup & Restore

Download a copy of this router's whole configuration — connections, keys, combos and settings — or restore one you saved earlier.

Download Backup

Saves a single JSON file containing every connection, API key, combo and setting.

⚠️ The file contains your provider tokens and password hash in plain text, so it can be used to sign in. Keep it somewhere private.

Restore From Backup

Replaces everything listed above with the contents of the file.

⚠️ This is a full replace, not a merge. Connections, API keys, combos and settings that are not in the file will be deleted. Usage history is kept.
