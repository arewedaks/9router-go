Change Password

Update the password used to sign in to this dashboard.

Reset Password

Clears the stored password and restores the built-in default, so you can get back in if the password is lost.

💾 Backup & Restore

Download a copy of this router's whole configuration — connections, keys, combos and settings — or restore one you saved earlier.

Download Backup

Saves a single JSON file containing every connection, API key, combo and setting.

⚠️ The file contains your provider tokens and password hash in plain text, so it can be used to sign in. Keep it somewhere private.

Restore From Backup

Replaces everything listed above with the contents of the file.

⚠️ This is a full replace, not a merge. Connections, API keys, combos and settings that are not in the file will be deleted. Usage history is kept.
